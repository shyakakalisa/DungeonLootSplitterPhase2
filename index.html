Logic Explanation

My program stores loot items in an array. Each item is an object with a name and value. When I add loot, the program checks the inputs before saving the item.

I use a for loop to calculate the total value of the loot. Another loop displays the items on the page. The list and total update when new loot is added.

I use if statements to check for missing names, invalid values, and invalid party sizes. When the user clicks Split Loot, the program divides the total by the number of party members.
