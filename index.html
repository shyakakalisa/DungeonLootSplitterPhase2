Logic Explanation

The loot array is the main source of information for my application. Each item stores its name, value, and quantity. I added quantity so users can enter multiple copies of an item without adding each one separately.

The updateUI() function calculates the total value of the loot and updates the interface whenever an item is added, removed, or the party size changes.

The application uses conditional statements to check whether the inputs are valid. This prevents invalid information from entering the loot array.

The application state determines which results are visible and whether the Split Loot button is enabled. This keeps the information on the screen consistent with the data.
